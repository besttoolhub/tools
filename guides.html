How-to guides

Get useful results from your files

These guides explain the basic workflow for each type of tool, what to check before you start, and where a conversion may change the original formatting.

Before you start

  1. Choose the tool that matches both your input file and the result you need.
  2. Keep an unchanged copy of important files before cleaning, merging, or converting them.
  3. Select your file and choose any format, size, order, or quality options shown by the tool.
  4. Download the result, open it in the intended application, and check that its contents and layout are usable.

Most file tools process files in your browser, and OCR images stay on your device. Large files or complex documents may take longer or exceed browser memory limits. AI proofreading is currently unavailable; Malayalam OCR, text imports, and local drafts remain available.

Document cleaners

Use a DOCX cleaner when you want to normalize Malayalam Unicode text or remove selected unwanted spacing characters and blank paragraphs from an English Word document. Choose a DOCX file, run the cleaner, and download the result. Compare the output with your original because document formatting can change.

Malayalam proofreading and OCR

Open the Malayalam Proofreader to type or import text, or recognize text from an image. OCR runs in your browser and its result can be edited and saved as a local draft. AI proofreading is currently unavailable.

For OCR, choose a printed or handwritten page image. The image is recognized in your browser and the extracted text is added to the editor for review. The OCR engine and Malayalam language data are downloaded from a third-party CDN. OCR results can contain errors, especially for handwriting or unclear images, so check the transcription before using it.

PDF and image conversion

Use PDF to Images to export PDF pages as images, or Images to PDF to arrange selected images and create a PDF. In the File Converter, choose a conversion mode first, then select the matching input file or files. For multi-page PDFs, the image tool may provide a ZIP containing the page images.

PDF conversions can simplify a document: for example, scanned PDFs may not contain selectable text, while converting Word or presentation files to PDF may not preserve images or design. Check the mode's on-screen notes and review every output.

Resize an image

Select an image, then choose a preset or enter the dimensions you need. Check the selected units and output format before saving. Cropping or changing dimensions can remove parts of an image or affect its appearance, so keep the original if you may need it later.

Merge HTML files

Select multiple HTML files or a folder of HTML files. Choose whether to merge the page bodies or concatenate the raw HTML source, then create and download the combined file. The two modes produce different results; open the output in a browser and inspect it before using it elsewhere.

Convert audio and video

Open the Audio Converter, choose a conversion mode, and select a supported audio or video file. Use the available controls to trim or adjust the output, then download and listen to the result. Long clips and high-quality settings can require more processing time and memory.

Need help?

If a tool fails or an output does not look right, try a smaller or simpler file, review the selected mode and format, and compare the result with your original. You can contact Team Tool Hub at besttoolkit@gmail.com.
