About us

Simple tools for everyday work.

Tool Hub is a collection of practical file tools maintained by Team Tool Hub. It is designed to help people handle common document and media tasks in one place.

What you can do here

  • Clean Malayalam and English Word documents.
  • Recognize Malayalam text from images and edit the transcription.
  • Convert PDF pages to images and combine images into a PDF.
  • Resize and crop images, including setting custom dimensions.
  • Merge HTML files by combining their page bodies or concatenating their source.
  • Convert between supported PDF, Word, spreadsheet, text, presentation, and image formats.
  • Convert, trim, and adjust audio and supported video files.

Designed for local processing

Tool Hub's file tools process selected files in your browser. Malayalam OCR images are recognized locally. AI proofreading is currently unavailable on this GitHub Pages site. See our Privacy Policy for details.

For practical usage instructions and known conversion limitations, see the Tool Hub guides.
